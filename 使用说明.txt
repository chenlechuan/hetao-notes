核桃便签 · 使用说明
================================================================

【一、怎么打开】

1. 先把压缩包**完整解压**到任意文件夹（比如 D:\核桃便签）。
   不要直接在压缩软件窗口里双击运行，那样会解压到临时目录，
   下次打开你的便签就"不见了"。

2. （可选）双击「创建桌面快捷方式.vbs」，会在桌面生成一个
   「核桃便签」快捷方式，以后双击桌面图标就能直接打开。

3. 双击 Launch.vbs 即可启动，没有安装过程，也没有控制台黑框。

4. 如果双击 Launch.vbs 没反应（系统禁用了 VBS），改双击 Launch.bat。
   如果 Launch.bat 提示 PowerShell 版本太旧，看下面第二节。

5. 第一次启动会自带 3 条示例任务，可以直接改，也可以删掉。


【二、系统要求】

· Windows 10 / Windows 11：直接可用，不需要装任何运行库。
  用的是系统自带的 Windows PowerShell 5.1 + .NET Framework，纯离线。

· Windows 8.1 / Windows 7 SP1：需要先安装
  Windows Management Framework 5.1（微软官网免费下载），
  另外 Win7/8 缺少 Segoe MDL2 图标字体，个别图标会显示成方块，
  功能不受影响，只是不太好看。建议用 Win10 及以上。


【三、安全软件提示怎么办】

本程序是"脚本 + 界面文件"，启动时调用了 PowerShell 的隐藏窗口方式，
部分安全软件（360、火绒、电脑管家）或公司的组策略会因此报警甚至拦截。
这是这类工具的通病，不是病毒。

· 弹出"是否允许运行"时选「允许 / 信任」。
· 被直接删除或隔离时，把整个文件夹加入信任区 / 白名单。
· 公司电脑如果被组策略强制禁止脚本，本程序无法运行，属于环境限制。


【四、你的便签存在哪】

全部在程序目录下的 data 文件夹里：

  data\notes.json        便签正文（主文件）
  data\notes.bak.json    上一版自动备份（主文件损坏时自动恢复用）
  data\draft.json        输入框里还没发出去的草稿
  data\exports\          你导出的 CSV

· 想带走便签：整个文件夹一起复制走即可。
· 换电脑 / 重装：把旧的 data 文件夹覆盖到新目录里。
· 想备份：只备份 data 文件夹就够，复制一份放网盘或 U 盘。
· 程序对写入做了保护（先写临时文件再原子替换），断电、强杀进程
  最多丢最后一次改动，不会把整个便签库写坏；万一手工改坏了主文件，
  启动时会自动用 notes.bak.json 恢复，并把坏文件另存为
  notes.corrupt.<时间>.json 方便排查。

⚠ 注意：数据跟着"程序所在的文件夹"走。如果你把文件夹换个位置，
  记得把 data 一起搬过去，否则会当成全新开始。如果程序放在
  C:\Program Files 这类没有写权限的位置，数据会自动改存到
  %APPDATA%\HetaoNotes，此时想备份请去那个目录找。


【五、常用操作】

· Ctrl + Alt + N      随时呼出 / 隐藏窗口（全局热键，任何程序下都能用）
· 关闭窗口            默认收进系统托盘，不退出；退出请用托盘右键菜单
· 顶部按钮            置顶、锁定、专注模式、设置
· 专注模式            Esc 退出，右下角斜线手柄可缩放
· 提醒                每条便签可设提醒时间，到点托盘气泡 + 应用内提醒卡
· 开机自启            设置里可开关（首次运行默认开启）
· 卸载                直接删掉整个文件夹即可，不留注册表垃圾；
                      如开着开机自启，先到设置里关掉再删


【六、常见问题】

Q：双击后完全没反应？
A：先试 Launch.bat，它会显示具体原因（找不到文件 / PowerShell 版本低）。
   都没提示的话，多半是安全软件静默拦截了，把文件夹加白名单再试。

Q：双击了两次，怎么只出现一个窗口？
A：这是有意的单实例设计，重复双击只会把已有窗口叫到最前面。

Q：提醒时间点我关机了，开机会补吗？
A：会。开机后自动补弹，同时托盘气泡 + 提示音。
   如果超过「补弹范围」（默认 24 小时，可在设置里改成 3 天 / 7 天 /
   不限时间），不会丢，会列进「已错过」清单——开机时弹一条提示，
   设置面板里也有入口，每条可以「重新提醒」或「忽略」。

Q：界面能换英文吗？
A：能。设置 → 外观 → 语言，选「English」即可，切换马上生效，不用重启。
   默认是「跟随系统」：中文系统显示中文，其他语言系统显示英文。
   便签正文、标签名这些你自己写的内容不会被翻译。

Q：图标变成方块或乱码？
A：系统缺少 Segoe MDL2 Assets 字体（Win7/8 常见），换 Win10/11 即可。

Q：便签突然全空了？
A：先别新建内容。检查是不是把程序文件夹挪了位置（数据在旧目录的
   data 里）；如果 data\notes.json 还在，把它和 notes.bak.json 一起
   发给我看。程序不会主动清空数据。

Q：能放到 U 盘 / 网盘同步目录吗？
A：可以。U 盘拔插时注意先退出程序（托盘右键退出）再拔，避免写入中断。
