# 核桃便签 HetaoNotes v1.01

一个轻巧、好看的绿色桌面便签 / 任务清单。纯 Windows 原生（PowerShell + WPF）实现，**免安装、无依赖、可离线使用**。

v0.75 新增：

- **写入不再怕断电**：`notes.json` 与 `draft.json` 一律先写同目录临时文件并强制刷盘，再用系统级原子替换（`File.Replace`）换上去，换的同时把上一版留成 `notes.bak.json`。断电 / 强杀 / 蓝屏只会丢最后一次改动，不会再出现「文件写了一半、整个便签库打不开」
- **坏文件自动抢救**：万一主文件真的坏了（手工改错、磁盘坏道），启动时不会当成空库，而是自动读 `notes.bak.json` 恢复，同时把坏文件另存为 `notes.corrupt.<时间>.json` 供排查，界面会提示「数据文件损坏，已用备份恢复」
- **双击更可靠**：启动时若发现另一个实例正在初始化或收尾（互斥体被占但窗口还没出现），会在 3 秒内反复找窗口唤醒；若期间对方已经退出，则自己接管而不是直接退出，避免「双击了却没反应」
- **修复无备份写入退化**：`draft.json` 这类不带备份的写入，`File.Replace` 的备份参数被 PowerShell 从 `$null` 自动转成了空字符串，每次都会抛「路径的形式不合法」并退化成「先删原文件再改名」——等于把刚做好的原子性又丢掉了，同时 `error.log` 每次多一条。现在显式传 `[NullString]::Value`，草稿、导出等所有写入都走真原子替换

## 快速开始

解压后直接双击：

```
Launch.vbs
```

如果 VBS 被安全软件 / 组策略拦截，可双击 `Launch.bat`——它会先做环境自检，把失败原因（找不到 `HetaoNotes.ps1` / `ui.xaml`，或 PowerShell 版本低于 5.1）直接显示出来，而不是双击后毫无反应。第一次启动会生成 3 条示例任务，可直接编辑或删除。

> 用 Git 克隆的话，进入仓库目录双击 `Launch.vbs` 即可；脚本按自身所在目录查找 `ui.xaml`，与从哪个目录启动无关。

## 分发（发给别人用）

把整个文件夹压缩后发给对方即可，**压缩前先删掉或排除 `data\`**，否则会连你自己的便签一起发出去。对方解压到任意**可写**目录、双击 `Launch.vbs` 即可，首次启动会自动新建空库。

对方解压后，也可以先双击文件夹里的 **`创建桌面快捷方式.vbs`**——它会自动识别当前目录、在桌面生成一个「核桃便签」快捷方式，以后双击桌面图标就能直接打开。

系统要求：Windows 10 / 11 开箱可用（自带 PowerShell 5.1 + .NET Framework，无需安装任何运行库）。Windows 7 SP1 / 8.1 需先安装 Windows Management Framework 5.1，且缺少 `Segoe MDL2 Assets` 字体，个别图标会显示成方块（功能不受影响）。

两个已知的环境差异：一是 `Launch.vbs` 依赖 Windows Script Host，公司组策略可能禁用，此时改双击 `Launch.bat`；二是启动时用了 `-ExecutionPolicy Bypass` + 隐藏窗口，360 / 火绒 / 管家 或 Defender 的 ASR 规则可能报警，需把整个文件夹加入信任。

> 请通过快捷方式 / `Launch.vbs` / `Launch.bat` 启动，不要直接双击 `HetaoNotes.ps1`。

## 任务规则

| 类型                 | 行为                                                              |
| ------------------ | --------------------------------------------------------------- |
| **单次**             | 未完成时每天自动顺延（卡片会显示「已顺延 N 天」）；完成后停留到次日，再自动归档到历史                    |
| **笔记**             | 没有勾选框、不参与完成率、不跨天顺延；不会被自动归档，只有主动删除才会离开列表                         |
| **每天 / 每周 / 每月循环** | 创建后当前周期出现一条；到达下个周期时自动新增一条。上一次没完成也不会丢，会标成「逾期」，和新任务同时存在；**不需要打卡** |
| 完成                 | 勾选左侧圆点；当天显示在「已完成」，次日归档到历史                                       |
| 类型切换               | 点击任务文字下方的类型文字（如「单次」/「每天循环」），可改为其他循环周期，或停止循环（当前任务保留为单次）          |
| 删除循环任务             | 右侧垃圾桶只删除「本次」；要停止整个循环，请点类型文字 → 停止循环                              |

## 使用说明

| 操作                 | 效果                                                             |
| ------------------ | -------------------------------------------------------------- |
| 底部输入 + `Enter`     | 添加任务（`Esc` 清空输入）                                               |
| 点击 `单次 ▾`          | 选择本次要添加的类型：单次 / 每天 / 每周 / 每月 / **笔记（无勾选框）**                    |
| 点击任务文字             | 直接编辑，自动保存；循环任务修改文字会同步到该循环系列                                    |
| 点击左侧圆点             | 完成 / 取消完成（笔记没有圆点）                                              |
| 双击「已完成」任务文字        | 取消完成                                                           |
| 点击类型文字             | 修改循环周期 / 转为笔记 / 停止循环                                           |
| 拖动左侧 `⋮`           | 调整顺序：卡片跟着光标浮起，落点高亮；拖出窗口时笔记会变成独立小窗                              |
| 点击任务右侧图钉           | 单条置顶（固定在「置顶」分组）                                                |
| 点击任务右侧回形针图标        | 归档到标签（可多选）/ 新建标签                                               |
| 任务右侧铃铛             | 给这条便签设提醒时间（`2026-10-31 09:00`、`10-31 09:00`、`2026-10-31` 都能识别） |
| 工具栏放大镜             | 搜索便签 / 历史（`Ctrl + F`）                                          |
| 右上角 📌             | 窗口始终置顶                                                         |
| 右上角图层按钮            | 半透明玻璃 / 实心背景                                                   |
| 工具栏「待办 / 历史 / 回收站」 | 切换任务、历史记录、回收站                                                  |
| 工具栏回形针按钮           | 组织管理：新建 / 改名 / 删除标签                                            |
| 搜索框右侧 `全部标签 ▾`     | 只看某个标签下的条目（再选「全部标签」取消）                                         |
| 右上角锁图标             | 锁定页面：禁止拖动 / 缩放 / 编辑 / 删除 / 勾选，再点一次解锁                           |
| 右上角斜箭头             | 进入专注小窗模式（`Esc` 退出）                                             |
| 右上角齿轮              | 设置：主题、透明度、时钟、提醒、托盘、热键、开机自启、导出、备份                               |
| 右上角 —              | 隐藏到系统托盘（若托盘已开启）                                                |
| 右上角 ✕              | 隐藏到系统托盘（若开启了「关闭时隐藏到托盘」）；托盘菜单「退出」真正退出                           |
| 拖动时钟区域             | 移动窗口（锁定后不可拖动）                                                  |
| 拖动右下角斜线手柄          | 缩放窗口（完整模式最小 440×540，专注小窗最小 200×160）                            |

快捷键：`Ctrl + N` 聚焦输入框、`Ctrl + F` 搜索、`Ctrl + H` 历史页、`Ctrl + D` 待办页、`Esc` 关闭弹出层 / 退出专注模式。

## 提醒

- 点便签右侧铃铛 → 输入时间回车，即可设置 / 修改；再点一次可改时间或取消
- 到点后：窗口顶部弹出提醒卡（可「稍后 5 分」或「完成」），同时托盘气泡 + 提示音（后两者可在设置里关）
- 「提前提醒」可选准时 / 提前 5 / 15 / 30 分钟；提前提醒用的还是同一条便签的提醒时间，不会改掉原时间
- 电脑关机错过提醒：开机后自动补弹。超出「补弹范围」（默认 24 小时，可在设置里改成 3 天 / 7 天 / 不限）的不会被丢掉，而是列进「已错过」清单，弹一条汇总提示，可逐条重新提醒或忽略
- 窗口藏在托盘时到点，会自动把主窗口叫出来
- **循环任务的提醒会跟着循环走**：给「每天循环」的任务设了今晚 9 点提醒，明天自动生成的待办就自动带明晚 9 点的提醒；改任何一个周期的提醒时间，后续周期都按新时间延续；取消提醒则整条循环链都不再提醒

## 主页时间与本周日历

- 完整模式默认窗口 800×600，拖动右下角斜线手柄可自由缩放，尺寸会记住
- 完整模式左上角是大号时间（`HH:mm` + 秒），下面一行是「2026年10月30日 星期五 · 晚上好」
- 再下面一条是**本周日历**：周一至周日七列，显示本周一到周日的日期数字，今天用主题色圆底高亮；跨月的周（如 10/26–11/1）会自然显示两个月份的数字
- 设置 → 时钟 可配 12 / 24 小时制、是否显示秒、是否显示本周日历
- 专注小窗里不显示时间与日历，只留列表

## 锁定与专注模式

| 模式     | 行为                                                                                                                                 | 退出                  |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| **锁定** | 窗口不能拖动 / 缩放；便签不能改、不能删、不能勾选；输入框、搜索、设置变灰                                                                                             | 点工具栏锁图标，或专注小窗顶部的锁图标 |
| **专注** | 隐藏时间、日历、进度、标签、搜索、设置、输入框；**不显示已完成条目，也不显示条目上的提醒 / 置顶 / 删除按钮**；默认 320×420，拖右下角斜线手柄可自由缩放（最小 200×160），列表按可用高度显示条数；顶部保留**置顶**与**锁定**两个开关 | 右上角箭头或 `Esc`        |

两者互相独立，也可以叠加：专注 + 锁定 = 钉在桌面角落只读的小清单。**锁定状态不跟随上次关闭**：每次启动都从「未锁定」开始（存档里 `locked` 恒为 `false`），避免昨天锁着、今天打开却拖不动；其余状态（位置、大小、主题、透明度、页签、专注、置顶）照旧沿用。

**怎么拖动窗口**

- 抓**时间 / 日期 / 周历**区域，或者卡片顶部那条空白，都能拖动；专注小窗抓顶部三个圆点那条细条
- 能拖的地方不包括按钮、输入框、列表条目
- 每次按下鼠标都会先清掉可能残留的鼠标捕获，所以不会出现「按下去没反应、得先锁一次再解锁才能拖」的情况

**专注小窗的尺寸与吸附**

- 拖动右下角斜线手柄改大小，松手后尺寸被记住，下次进专注模式沿用；完整模式与专注模式的尺寸分别记忆
- 窗口拖到屏幕左/右/上/下边缘 18 像素以内会自动贴合边缘，**贴边后不会自动收起**，照常可用
- 拖动位置、尺寸都随数据保存，重启后回到原处

## 笔记条目、组织管理与回收站

**笔记条目**

- 两种添加方式：底部 `单次 ▾` 选「笔记（无勾选框）」，或点已有条目的类型文字 → 「转为笔记」
- 没有勾选框、不计入「待办 N / 今日完成」、不会被跨天顺延；编辑、提醒、标签、拖动、置顶都照常
- 列表里单独归到一个「笔记」分组，待办分组在上

**把笔记拖成独立小窗**

- 抓住笔记条目的 `⋮` 往窗口外拖，松手后生成一个小窗：圆角卡片、`笔记 · 拖动可移动` 标题、右上角关闭、右下角缩放手柄
- 小窗只能拖动、缩放、关闭，没有编辑与勾选
- **关掉小窗不等于删除**：内容仍在完整模式里，也不进历史；只有在完整模式点删除才会进回收站
- 同一条笔记重复拖出只会把已有小窗提到前面，不会开第二个

**组织管理（标签）**

- 工具栏回形针按钮打开「组织管理」：输入名称 → 新建；每行可改名（直接点名字改）、按标签筛选、删除
- 删除标签只删标签本身，条目会保留（只是不再属于该标签）
- 给条目打标签：点条目右侧的回形针图标，菜单里勾选 / 取消；`新建标签…` 会顺手把当前条目归到新标签
- 归档后的标签以 `#标签名` 形式显示在类型文字后面，点它也能打开同一个菜单
- 搜索框右侧 `全部标签 ▾` 按标签筛选，选中后按钮变成 `#标签名`；`清除筛选` 按钮或在菜单里选「全部标签」可取消

**回收站**

- 删除待办 / 历史 / 笔记都会先进回收站（顶部提示「已移入回收站，可随时还原」）
- 回收站里每条显示删除时间，两个按钮分别是「还原」和「彻底删除」，底部还有「清空回收站」
- 还原会回到原来的位置，标签、置顶、提醒一起恢复；来自历史的记录会还原到历史页
- 彻底删除 / 清空是不可撤销的（清空前会弹确认框）

**自动保存**

- 输入框里的内容每敲一个字都会在约 200 毫秒后写入 `data\draft.json`，与 `notes.json` 分开
- 关闭窗口、隐藏到托盘、系统关机（`SessionEnding`）都会再刷一次
- 下次启动自动把草稿回填到输入框；发送出去或按 `Esc` 清空后草稿文件会被删掉
- 条目正文的修改依旧是即时写 `notes.json`


## 历史记录

- 完成的任务当天仍显示在「已完成」；**次日首次运行 / 跨零点时自动归档**到历史
- 历史页按完成日期分组（不显示统计数字，只看清单）
- 每条历史可「重新加入待办」或删除；支持导出 Markdown / CSV
- 任务如果跨多天未打开应用，下次启动会一次性完成归档，并只为每个循环系列补一条最新任务（不刷屏）

## 主题与透明度

- 设置 → 外观 → 9 套主题色卡，点击即时切换，自动保存
- 深色 6 套：青柠绿、森林绿、海盐蓝、樱花粉、暖阳橙、极夜黑
- 传统便签亮色 3 套：便签黄、便签白、便签粉（浅底深字，文字、图标、卡片边框一起换色）
- 背景透明度：滑杆 40%–100%，或「清透 55% / 标准 86% / 沉稳 92%」快捷档
- 透明度只作用于背景层，文字、按钮保持清晰；实心模式下透明度滑杆自动禁用
- 弹出菜单（类型 / 提醒 / 归档标签 / 标签筛选）的底色、边框、悬停高亮、分隔线都会跟着主题重算：亮色主题下是浅底深字，深色主题下是深底浅字，不会再出现深底配深字看不清的情况

## 系统托盘 / 热键 / 开机自启

- 默认开启托盘图标；右键托盘图标可显示/隐藏、打开设置、退出
- 关闭按钮与最小化按钮会隐藏到托盘；再次双击快捷方式或按 `Ctrl + Alt + N` 可呼出
- 全局快捷键、关闭到托盘、开机自启都可以在设置里分别开关
- 开机自启写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`；如果被系统策略阻止，开关会自动恢复为关闭并提示

## 数据与备份

- 数据文件：`HetaoNotes\data\notes.json`（**v4 Schema**，UTF-8 JSON；新增 `mode`（待办 / 笔记）、任务 `tags`、全局 `tags` 与 `trash` 数组）；输入框草稿单独存在 `data\draft.json`
- 每次保存都会顺手留一份上一版的 `data\notes.bak.json`：主文件损坏时启动会自动读它恢复，并把坏文件存成 `data\notes.corrupt.<时间>.json`
- 写入采用「临时文件 + 刷盘 + 原子替换」，中途断电或强杀进程都不会留下半截 JSON
- 从 v1 / v2 / v3 升级都会自动兼容：缺字段按默认值补齐，指向已删除标签的悬空引用会被丢掉
- 从 v1 升级：会自动把旧便签迁移为「单次」任务，并保留 `data\notes.v1.backup.json`；v2 数据可直接读取
- 导出 / 备份文件保存在 `data\exports\`：
  - `便签记录_*.csv`：待办 + 历史全量导出，列含 状态 / 内容 / 创建时间 / 提醒时间 / 循环情况 / 完成时间
  - `历史_*.md`：历史记录 Markdown 导出
  - `backup_*.json`：全部数据备份（可在设置里「恢复最近备份」或「从文件恢复」）
- 恢复前会自动保存当前数据为 `data\notes.before-restore.*.json`
- 删除整个 `data` 文件夹即可重置；程序目录不可写时数据自动改存 `%APPDATA%\HetaoNotes`
- 移动程序时请把整个 `HetaoNotes` 文件夹一起复制

## 常见问题

- **窗口不见了？** 按 `Ctrl + Alt + N`，或再次双击快捷方式（会自动把已有窗口调到前台，不会开第二个）；也可以点托盘图标。托盘菜单「退出」才会真正退出。
- **双击没反应？** 确认 `Launch.vbs` 与 `HetaoNotes.ps1`、`ui.xaml` 在同一文件夹；首次运行如遇 SmartScreen / 杀毒软件提示，请选择允许（脚本只读写本地数据，不联网）。
- **开机自启失败？** 某些公司电脑 / 安全策略会禁止写注册表启动项；开关会自动回到关闭，不影响其他功能。
- **透明度调太低看不清？** 建议不低于 60%；默认「标准 86%」在大多数壁纸上都清晰。
- **历史记录在哪？** 见 `data\notes.json` 的 `history` 数组，或直接在设置里导出。
- **升级后旧数据还在吗？** 在。首次启动 v2 会自动迁移旧版 `notes`，并保留 `notes.v1.backup.json`。
- **提醒没弹出来？** 确认便签右侧铃铛是亮的（设过提醒），且主程序在运行；窗口藏在托盘也会被叫出来。系统时间被手动改过时可能错过提醒，重启应用即可重新计算。
- **窗口拖不动？** 抓时间 / 日期 / 周历区域或卡片顶部空白都能拖，按钮和列表上不行；先点一下窗口让它到前台再拖最稳。锁定状态下本来就禁止拖动，点工具栏锁图标解锁。
- **锁定后改不了字？** 这是设计如此，点工具栏的锁图标解锁即可。锁定状态**不会**记忆，下次打开自动是未锁定。
- **专注模式下找不到设置？** 专注模式只保留顶部的置顶 / 锁定 / 退出三个按钮，其余按钮隐藏；按 `Esc` 或点右上角箭头回到完整模式。
- **标签删了条目还在吗？** 在。删标签只影响标签本身，条目会保留在列表里，只是不再带 `#标签名`。
- **拖出去的笔记小窗关掉会丢内容吗？** 不会。关小窗只是收起那个浮窗，条目仍在完整模式列表里，也不进历史；要真正删掉请在完整模式点垃圾桶。
- **刚写的字会不会没存？** 不会。输入框内容每 200 毫秒写一次 `data\draft.json`，关窗 / 关机再刷一次；下次打开自动回填。
- **回收站会自己清空吗？** 不会，只有手动「彻底删除 / 清空回收站」才会真正删掉。
- **断电会不会把便签库写坏？** 不会。写入走「临时文件 + 刷盘 + 原子替换」，最坏情况只丢最后一次改动；真遇到主文件损坏，启动会自动用 `data\notes.bak.json` 恢复并提示，坏文件另存为 `notes.corrupt.*.json`。
- **备份文件能手动还原吗？** 能。把 `notes.bak.json` 改名成 `notes.json` 覆盖即可，或在设置里用「从文件恢复」选它。

## 自检（可选，给维护用）

改完代码不想手动点一遍，可以跑无界面自检：

```powershell
powershell -STA -File .\HetaoNotes.ps1 -SmokeTest
```

它会在临时目录里跑一遍建任务 → 完成 → 跨天归档 → 提醒触发 → 锁定 → 专注（含缩放记忆、贴边吸附、按钮显隐、缩放下限）→ 本周日历 → 九套主题 → 笔记模式（无勾选框 / 不计入完成率）→ 标签（新建 / 归档 / 筛选 / 改名 / 菜单弹层）→ 回收站（删除 / 还原 / 彻底删除 / 顶部进度刷新）→ 草稿读写 → 抗损坏（原子写入无残留临时文件 / 主文件损坏后从备份恢复 / 坏文件留存）→ CSV 导出 → 存档往返，逐项打印 OK / FAIL，最后输出 `SMOKE_ALL_PASSED`。**不会碰你的真实数据，也不会写开机自启**。加 `-SmokeTest` 时还会把主界面、设置面板、专注模式、锁定状态的截图存到系统临时目录，方便目检布局；加 `-Theme noteyellow` 可以让截图换成指定的亮色主题。
